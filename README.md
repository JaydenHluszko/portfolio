# 👨‍💻 Jayden Hluszko — Personal Portfolio & Technical Case Studies

[![Website Status](https://img.shields.io/website?url=https%3A%2F%2Fjaydenhluszko.netlify.app&style=flat-square)](https://jaydenhluszko.netlify.app/)

A modern, server-side rendered (SSR) portfolio and case study platform built for **Jayden Hluszko**, Full Stack Consultant & Engineer. The platform highlights engineering projects, technical case studies, skills architecture, and professional experience.

## 🚀 Live Site
[jaydenhluszko.netlify.app](https://jaydenhluszko.netlify.app/)

## ✨ Key Features
- **In-Depth Case Studies:** Dedicated multi-page architectural writeups (`/case-studies/`) detailing complex software solutions (AI Claim Builder, Growth-Driven Redesign, Multi-Tenant Design System).
- **Interactive Resume:** Web-based CV view (`resume.vue`) formatted for quick scanning and recruiter accessibility.
- **Modular Component Design:** Encapsulated Vue components including reusable technology chips (`TechChip.vue`), project preview cards (`ProjectCard.vue`), and connection callouts (`LetsConnect.vue`).
- **High-Performance SSR:** Optimized rendering speeds, dynamic meta handling, and search engine visibility powered by Nuxt 3.

## 🛠️ Tech Stack
- **Framework:** Nuxt 3 / Vue 3
- **Language:** TypeScript / JavaScript
- **Styling:** CSS / Tailwind
- **Hosting & Deployment:** Netlify
